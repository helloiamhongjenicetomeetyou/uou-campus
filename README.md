## 소개

**울산대 캠퍼스 길찾기**는 무거캠퍼스 안에서 두 건물 사이 가장 빠른 길을 찾아 주는 웹 서비스입니다.

카카오·네이버·구글 길찾기는 캠퍼스 안을 모릅니다. 차량 경로가 기본이고, 보행 경로를 준다 해도
학교 안쪽 보행로·계단·건물 사이 통로는 데이터에 없습니다. 정문에서 전기/컴퓨터공학관까지 찍으면
대학로를 따라 빙 도는 길이 나옵니다.

## 주요 기능

### 1. 캠퍼스 보행망 직접 구축
> 보행로도 계단도 지름길도, 학교 안 길을 통째로 들고 있어요.

- 노드 332개 (건물 42 · 출입문 3 · 길목 287), 간선 420개 (차도 195 · 보행로 192 · 계단 33)
- 길 형상·건물 위치는 OpenStreetMap 실측 ([relation/9762419](https://www.openstreetmap.org/relation/9762419))
- 캠퍼스 안내도에 노란색으로 칠해 둔 **지름길 52개 구간**을 따로 표시
- 이진 힙 다익스트라. 간선 비용이 음수가 될 일이 없어 A\* 없이 충분

### 2. 세 가지 기준으로 비교
> 짧은 길과 빠른 길은 다릅니다. 아는 길은 또 다르고요.

- **최단거리** — 걷는 거리를 최소화
- **최소시간** — 바닥에 따라 같은 거리도 다르게 셈 (계단은 평지의 2.2배 + 진입 4초)
- **지름길 우선** — 표시된 지름길을 0.45배로 쳐서 아는 길로 붙임
- 답이 다를 때만 다른 기준의 경로를 **주황 점선**으로 겹쳐 표시
- 큰길로만 돌았을 때와 견줘 **몇 분을 벌었는지** 계산

### 3. 이름 · 번호 · 별명으로 찾기
> 7, 전컴관, ICT융합학부가 전부 같은 곳이에요.

- 목록에 오르는 곳 45개. 건물 번호는 캠퍼스 공식 안내도의 범례 그대로
- 좁은 화면에서는 **전체 화면 목록** — 검색, 번호순, 별칭, 현위치에서 몇 m
- **지도에서 고르기** — 시트를 내려 지도만 남기고, 근처 120m 안을 대충 눌러도 잡힘
- 넓은 화면에서는 칸 밑에 붙는 드롭다운

### 4. 실시간 따라가기
> 걸으면서 다음에 뭘 할지 한 줄만 보면 돼요.

- 위치를 경로 위로 끌어당겨 남은 거리·시간 계산
- 상단에 **다음 동작 하나만** 크게 — "80m 뒤 / 오른쪽으로 꺾기"
- 지나온 구간은 회색, 남은 길만 초록
- 지도가 현위치를 따라감. 배율은 처음 한 번만 맞추고 이후 손대지 않음
- 이탈 판정은 **35m 와 GPS 오차 반경의 1.5배 중 큰 쪽**
- 어림한 좌표(오차 50m 초과)로는 출발지를 잡지 않음. 지도에는 오차 반경을 원으로 표시

### 5. 폰에서는 화면이 단계마다 바뀜
> 손바닥만 한 화면에서 지도가 주인공이 되게.

| 단계 | 화면 |
|------|------|
| 고르는 중 | 시트가 펼쳐지고, 칸을 누르면 전체 화면 목록 |
| 지도에서 고르기 | 시트가 화면 밖으로 내려가고 지도만 |
| 경로 나옴 | 시트가 저절로 접혀 요약 한 줄만 |
| 안내 중 | 위쪽에 다음 동작, 지도는 현위치를 따라감 |

- 시트 손잡이를 끌어 접고 펴기. 접힌 높이는 손잡이 칸을 실제로 재서 사용
- 손으로 잡아 둔 시트 자리는 그 구간을 보는 동안만 유지

### 6. 가로로 돌리면 시트가 기둥이 됩니다
> 세로로 길 때와 가로로 납작할 때, 남는 자리의 모양이 정반대입니다.

세로로 든 폰은 위아래가 길어 아래에서 올라오는 시트가 맞습니다. 그대로 가로로
돌리면 높이가 390px 남짓이라 같은 시트가 화면의 3/4 을 물고, 지도에 90px 만
남습니다 — 캠퍼스가 한 줄로 눌립니다. 가로에서는 폭이 남으니 옆을 내줍니다.

| | 세로로 들었을 때 | 가로로 돌렸을 때 |
|--|------|------|
| 길찾기 패널 | 아래에서 올라오는 시트 | 왼쪽 기둥 (폭의 44%, 최대 330px) |
| 곳 고르기 | 전체 화면 목록 — 한 칸씩 | 전체 화면 목록 — 두 칸씩 |
| 상단 안내 띠 | 화면 맨 위 전체 폭 | 기둥을 비켜 오른쪽 |
| 지도에서 고르기 | 시트가 아래로 빠짐 | 기둥이 왼쪽으로 빠짐 |

- 갈림은 폭이 아니라 **높이 500px 과 화면 방향**으로 봅니다. 요즘 폰은 가로로
  들면 폭이 850px 을 넘어 폭만 보면 '넓은 화면' 으로 잡히기 때문입니다
- 폭에도 위(1024px)를 막아 둡니다 — 데스크톱에서 창을 낮게 눌러 놓은 것까지
  걸리면, 마우스로 쓰는 사람에게 전체 화면 목록이 튀어나옵니다
- 돌리면 보던 자리를 다시 맞춥니다. 손으로 넓혀 본 화면과 걷는 중인 화면은 둡니다
- 노치와 홈 바는 가로에서 좌우로 옵니다. `env(safe-area-inset-left/right)` 를 따로 챙깁니다

### 7. 설치 없이, 끊겨도
> 캠퍼스 안은 신호가 잘 죽어요.

- 로그인·설치 없이 브라우저에서 바로
- 홈 화면에 추가하면 앱처럼 (PWA). iOS는 안내 문구로 대체
- 서비스 워커가 앱 껍데기와 한 번 본 지도 타일 500장을 캐시
- 그래프는 번들에 들어 있어 애초에 네트워크를 안 탐

### 8. 편집 모드
> 틀린 곳은 그 자리에서 고쳐요.

- `?edit=1` — 지점 추가, 종류(건물·시설·출입문·길목) 지정, 좌표 끌어 맞추기
- 좌표 신뢰도(`근사치` / `맞춘 좌표`)를 직접 표시
- 길 잇기, 바닥·지름길·비 가림 지정
- 길에 안 이어진 곳은 그 자리에서 경고
- **모두에게 저장** — 암호를 확인하고 저장소에 커밋 → 재배포 → 모두에게 반영

### 9. 통계
> 어디서 어디로 다니는지 알아야 고칠 자리가 보여요.

- Google Analytics 4. 측정 ID가 없으면 **번들에서 통째로 빠짐**
- `route_missing` — 길이 없다고 끝난 조합. 그래프에 빠진 길이라는 신호
- 좌표와 위치 기록은 보내지 않음. 추적 거부(DNT·GPC) 존중

## 기술 스택

| 구분 | 기술 |
|------|------|
| UI | React 19, TypeScript |
| 스타일 | vanilla-extract (제로 런타임 CSS-in-TS) |
| 지도 | Leaflet 1.9, OpenStreetMap 타일 |
| 길찾기 | 직접 구현 (이진 힙 다익스트라) |
| 빌드 | Vite 8, pnpm |
| 서버 | 없음 (정적 파일). 저장 기능만 Vercel 서버리스 함수 1개 |
| 배포 | Vercel |
| 데이터 | Overpass API → 시드 스크립트 → campus.json |

## 프로젝트 구조

```
campus-route/
├── api/
│   └── publish.ts                # 고친 지도를 저장소에 커밋 (유일한 서버 코드)
│
├── scripts/
│   ├── fetch-osm.mjs             # 오버패스 API → osm-campus.json
│   ├── seed-campus.mjs           # OSM 원본 + 사람이 아는 것 → campus.json
│   └── make-icons.mjs            # 워드마크 → 아이콘 다섯 벌
│
├── src/
│   ├── routing/                  # 길찾기 — 서버가 아니라 여기서 돈다
│   │   ├── geo.ts                # 거리·방위각·경계상자
│   │   ├── graph.ts              # 인접 리스트, 가장 가까운 노드
│   │   ├── cost.ts               # 세 기준과 시간 모형
│   │   ├── dijkstra.ts           # 이진 힙 다익스트라
│   │   ├── route.ts              # 경로 요약 (거리·시간·계단·지름길)
│   │   ├── progress.ts           # 위치를 경로에 붙이고 남은 거리 계산
│   │   └── directions.ts         # 턴바이턴 안내문
│   │
│   ├── components/
│   │   ├── Map/                  # Leaflet 을 감싼 한 겹
│   │   ├── RoutePanel/           # 길찾기 · 요약 · 안내문 (폰에서는 접히는 시트)
│   │   ├── PlacePicker/          # 폰에서 곳을 고르는 전체 화면 목록
│   │   ├── TopBar/               # 안내 한 줄, 지도에서 고르기 알림
│   │   ├── InstallButton/        # 홈 화면 설치
│   │   ├── EditorPanel/          # 좌표 맞추기 · 내보내기 · 모두에게 저장
│   │   └── common/               # Chip · Toggle · PlaceField
│   │
│   ├── hooks/                    # 그래프 편집, 현위치, 설치, 위치 시뮬레이터
│   ├── data/campus.json          # 그래프 (생성물)
│   ├── analytics/gtag.ts         # 측정 ID 가 있을 때만 붙는 통계
│   └── styles/                   # 색·글꼴·간격·화면 모양 토큰
│
└── public/                       # 서비스 워커, 아이콘, 매니페스트, og.png
```

## 아키텍처

```
┌──────────────────┐
│      View         │  React 컴포넌트 + Leaflet
├──────────────────┤
│      State        │  App.tsx 한 곳에서 화면 단계를 결정
├──────────────────┤
│     Routing       │  다익스트라 · 시간 모형 · 진행 추적 (전부 브라우저)
├──────────────────┤
│      Data         │  campus.json (번들) ← 편집분은 localStorage 가 덮어씀
└──────────────────┘
```

서버가 없습니다. 그래프는 빌드할 때 번들에 박히고, 길찾기는 사용자 기기에서 끝납니다.
편집한 내용은 그 브라우저에만 남고, 「모두에게 저장」을 눌러야 저장소로 올라갑니다.

## 데이터 출처

| 무엇 | 어디서 |
|------|--------|
| 길 형상 · 건물 위치 | OpenStreetMap ([ODbL](https://www.openstreetmap.org/copyright)) |
| 계단 · 터널 · 지하 통로 | OSM `highway=steps`, `tunnel`, `covered` 태그 |
| 건물 번호 · 별칭 | 캠퍼스 공식 안내도 범례 (사람이 얹은 유일한 값) |
| 지름길 52개 구간 | 안내도에 노란색으로 칠해 둔 길 |

건물 좌표는 출입구가 아니라 **건물 중심**입니다. 짧은 경로일수록 오차 비율이 큽니다.
